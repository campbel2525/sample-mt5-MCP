# GOLDのパーフェクトオーダー売り検証

## 結論

- SMA5、SMA20、SMA60を使うショート2,232通りを比較した。
- 3期間の利益順位では、4時間足中2つ以上が`SMA5 < SMA20 < SMA60`になった時に売り、M15の下降パーフェクトオーダーが崩れたら買い戻す方法が1位だった。
- 全期間のスプレッド調整後合計価格差は`935.88`、過去1年は`1079.06`、過去半年は`1086.95`だった。
- M5、M15、M30、H1のすべてが下降パーフェクトオーダーになった時だけ売る当初案は、H1の並びが崩れたら買い戻す方法が最良だった。
- 当初案は全期間104件、スプレッド調整後合計価格差`846.40`だった。

## 検証条件

- データと期間は検証1と同じ。
- 使用時間足: M5、M15、M30、H1
- 移動平均: 終値のSMA5、SMA20、SMA60
- 下降パーフェクトオーダー: `SMA5 < SMA20 < SMA60`
- 売りシグナル確認後のM5始値で新規売りする。
- 買い戻しシグナル確認後のM5始値で決済する。
- 各戦略につき1ポジションとする。
- 記録済みスプレッドを買い戻し価格へ加えて集計する。
- 手数料、スリッページ、スワップは含めない。
- 実際の注文、決済は行わない。
- 買い検証を反転した72の新規売り条件と31の買い戻し条件を比較した。
