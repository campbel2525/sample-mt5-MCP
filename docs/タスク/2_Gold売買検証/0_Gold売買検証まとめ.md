# GOLD売買検証まとめ

## 結論

今回検証した中で一番良かったのは、次のロングとショートを独立して動かす方法だった。

- ロング:
  - SMA15、SMA30、SMA60を使う。
  - M15とH1の両方が`SMA15 > SMA30 > SMA60`になったら買う。
  - 決済後も並びが成立していれば再エントリーする。
  - M30とH1の両方が上昇パーフェクトオーダーになった後、どちらかの並びが崩れたら売る。
  - 保有中の最高値から価格幅80下がった場合も売る。
- ショート:
  - SMA10、SMA30、SMA60を使う。
  - H1のSMA10がSMA30をデッドクロスしたら売る。
  - 4時間足中2つ以上が`SMA10 < SMA30 < SMA60`になった後、成立が2時間足未満になったら買い戻す。
  - 売値から価格幅120上昇した場合も買い戻す。
  - 2,880分経過した場合も買い戻す。
- ロングとショートはそれぞれ最大1件とし、同時保有を許可する。
- シグナルは確定バーだけで判定し、確認後のM5始値で取引する。

結果は次のとおり。

| 期間 | 取引数 | スプレッド調整後合計価格差 | 最大ドローダウン | プロフィットファクター |
| ---- | -----: | -------------------------: | -----------------: | -----------------------: |
| 全期間 | 296 | 3934.98 | 213.72 | 2.39 |
| 過去1年 | 217 | 3714.70 | 213.72 | 2.72 |
| 過去半年 | 101 | 1651.80 | 213.72 | 2.41 |

- 全体で1ポジションだけに制限する場合も、同じロングとショートの組み合わせが有力だった。
- 1ポジション限定の全期間は288件、スプレッド調整後合計価格差`3721.13`、最大ドローダウン`260.04`、プロフィットファクター`2.34`だった。
- 全期間の合計価格差だけを最大にするなら別の組み合わせが`4314.04`だったが、最大ドローダウンと過去半年の結果を含めると上記の方法を最良候補とした。

## ロングとショートの上位2方法

次の順位は、3期間の利益、最大ドローダウン、プロフィットファクター、取引数を合わせた総合判断である。

| 方向・順位 | 売買条件 | 全期間 | 過去1年 | 過去半年 |
| ---------: | -------- | -------: | -------: | -------: |
| ロング1位 | SMA15・30・60。M15、H1の上昇パーフェクトオーダーで買い、決済後も成立中なら再エントリーする。M30またはH1の並びが崩れるか、最高値から80下落したら売る | 147件 / 2533.93 / DD 91.78 | 110件 / 2204.69 / DD 91.78 | 42件 / 711.21 / DD 91.78 |
| ロング2位 | SMA10・30・60。4時間足中3つの上昇パーフェクトオーダーで買い、決済後も成立中なら再エントリーする。M5の並びが崩れるか、最高値から120下落したら売る | 777件 / 2557.62 / DD 202.84 | 563件 / 2411.63 / DD 189.03 | 200件 / 811.28 / DD 161.23 |
| ショート1位 | SMA10・30・60。H1のSMA10・SMA30デッドクロスで売り、下降パーフェクトオーダー成立が2時間足未満、価格が120上昇、または48時間経過で買い戻す | 149件 / 1401.05 / DD 202.22 | 107件 / 1510.01 / DD 202.22 | 59件 / 940.59 / DD 202.22 |
| ショート2位 | SMA10・20・60。M30の下降パーフェクトオーダーで売り、M15の下降パーフェクトオーダーが崩れたら買い戻す | 258件 / 971.53 / DD 352.51 | 180件 / 1178.90 / DD 252.86 | 100件 / 1093.26 / DD 224.38 |

- 各結果欄は`取引数 / スプレッド調整後合計価格差 / 最大ドローダウン`の順。
- ロング1位はロング2位より全期間の合計価格差が`23.69`小さいが、取引数と最大ドローダウンが大幅に少ないため1位とした。
- ショート1位はショート2位より過去半年の合計価格差が`152.67`小さいが、全期間の利益が大きく最大ドローダウンも小さいため1位とした。
- ロングの追従決済を0.25%〜5%でも比較したが、ロング1位の固定幅80とロング2位の固定幅120を上回らなかったため、順位と売却条件は変更しなかった。

## 検証範囲と注意点

- 入力: `data/タスク/2_Gold売買検証/1_Goldの売買タイミング/202608271557/market_history.json`
- 全期間: `2025.03.27 08:40:00`以上、`2026.08.25 20:00:00`未満
- 過去1年: `2025.08.25 20:00:00`以上、`2026.08.25 20:00:00`未満
- 過去半年: `2026.02.25 20:00:00`以上、`2026.08.25 20:00:00`未満
- MT5取引サーバー時刻を使用した。
- 記録済みスプレッドを含めた。
- 手数料、スリッページ、スワップは含めていない。
- 最大ドローダウンは、決済済み取引の累積価格差から計算した。保有中の含み損は含めていない。
- 多数の条件を同じ履歴で比較しているため、この結果だけで将来も同じ成績になることは確認できない。
- この最良候補は、今回のデータと比較条件の中での結論である。
- 実際の注文、決済は行っていない。
