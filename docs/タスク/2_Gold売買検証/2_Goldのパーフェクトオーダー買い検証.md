# GOLDのパーフェクトオーダー買い検証

## 結論

- SMA5、SMA20、SMA60を使うロング2,232通りを比較した。
- 当初案どおりM5、M15、M30、H1のすべてが`SMA5 > SMA20 > SMA60`になった時だけ買う条件では、M15のSMA5・SMA60デッドクロスで売る方法が最良だった。
- 当初案の結果は、全期間154件、スプレッド調整後合計価格差`2442.09`、最大ドローダウン`236.08`だった。
- 買い条件も自由に比較すると、M30とH1のパーフェクトオーダーで買い、成立時間足が3つ未満になったら売る方法が1位だった。
- ただし、別の移動平均期間まで含めると、SMA5、SMA20、SMA60が最良とはならなかった。

## 検証条件

- 入力: `data/タスク/2_Gold売買検証/1_Goldの売買タイミング/202608271557/market_history.json`
- 全期間: `2025.03.27 08:40:00`以上、`2026.08.25 20:00:00`未満
- 過去1年: `2025.08.25 20:00:00`以上、`2026.08.25 20:00:00`未満
- 過去半年: `2026.02.25 20:00:00`以上、`2026.08.25 20:00:00`未満
- 時刻: MT5取引サーバー時刻
- 使用時間足: M5、M15、M30、H1
- 移動平均: 終値のSMA5、SMA20、SMA60
- 上昇パーフェクトオーダー: `SMA5 > SMA20 > SMA60`
- 判定: 各M5時刻で、その時点より前に確定した各時間足の最新バーを使う。
- 約定価格: シグナル確認後のM5始値
- ポジション: 各戦略につき1つ
- 価格差: 記録済みスプレッドを買値へ加えた値も集計する。
- 含めないコスト: 手数料、スリッページ、スワップ
- 実際の注文、決済は行わない。

比較した条件は次のとおり。

- 買い条件72通り:
  - 1つ以上の時間足でパーフェクトオーダーが完成
  - 任意の時間足の組み合わせでパーフェクトオーダーが完成
  - 4時間足中1、2、3、4時間足以上でパーフェクトオーダーが完成
  - 決済後、条件が成立中なら再エントリー
  - 各時間足の短期・中期または短期・長期ゴールデンクロス
  - ゴールデンクロスへパーフェクトオーダー確認を追加
  - 検証1のM30、H1買い条件
- 売り条件31通り:
  - 各時間足のSMA5・SMA20またはSMA5・SMA60デッドクロス
  - 任意の時間足のパーフェクトオーダーが崩れる
  - パーフェクトオーダーの成立時間足数が指定数未満になる
  - SMA5がSMA60を下回る時間足数が指定数へ達する
