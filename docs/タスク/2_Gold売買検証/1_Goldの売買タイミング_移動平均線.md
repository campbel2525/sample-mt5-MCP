# GOLDの売買タイミング移動平均線検証

- 目的: GOLDをM30またはH1のゴールデンクロスで買い、どの時間足のデッドクロスで売る方法が良いかを比較する。
- 検証数:
  - M30で買う6通り
  - H1で買う8通り
  - 合計14通り
- 順位: 合計価格差が高い順
- 損益: `売値 - 買値`の合計
- 売買方向: 買い取引だけ
- 使用指標: 終値のSMA5、SMA20、SMA60
- 含めないもの: スプレッド、手数料、スリッページ、スワップ、固定利確、損切り、RSI、波動、ローソク足パターン
- 検証は過去データによるシミュレーションであり、MT5への注文や決済は行わない。

結論は次のとおり。

- 全期間の1位は、M30のSMA5・SMA60ゴールデンクロスで買い、M30のSMA5・SMA60デッドクロスで売る方法。
- 全期間の合計価格差は`1328.96`、取引数は215件。
- H1で買う方法の最高は、H1のSMA5・SMA60デッドクロスで売る方法で、全期間2位の`1297.81`。
- 過去1年も全期間と同じ方法が1位。
- 過去半年は、M30で買い、M15のSMA5・SMA20デッドクロスで売る方法が1位。

## 売買ルール

### 購入

- M30買い:
  - M30のSMA5がSMA60をゴールデンクロスした確定バーを買いシグナルとする。
  - 次のM30バーの始値で買う。
  - 買い時刻の直前に確定したM5またはM15のどちらかで`SMA5 < SMA60`の場合は購入しない。
  - M5とM15の両方で`SMA5 >= SMA60`の場合だけ購入する。
- H1買い:
  - H1のSMA5がSMA60をゴールデンクロスした確定バーを買いシグナルとする。
  - 次のH1バーの始値で買う。
  - 買い時刻の直前に確定したM5、M15、M30のいずれかで`SMA5 < SMA60`の場合は購入しない。
  - M5、M15、M30のすべてで`SMA5 >= SMA60`の場合だけ購入する。
- SMA5とSMA60が同値の場合は購入できるものとする。

### 売却

- M30買いは次の6通りを比較する。
  - M5のSMA5・SMA20デッドクロス
  - M5のSMA5・SMA60デッドクロス
  - M15のSMA5・SMA20デッドクロス
  - M15のSMA5・SMA60デッドクロス
  - M30のSMA5・SMA20デッドクロス
  - M30のSMA5・SMA60デッドクロス
- H1買いは次の8通りを比較する。
  - M5のSMA5・SMA20デッドクロス
  - M5のSMA5・SMA60デッドクロス
  - M15のSMA5・SMA20デッドクロス
  - M15のSMA5・SMA60デッドクロス
  - M30のSMA5・SMA20デッドクロス
  - M30のSMA5・SMA60デッドクロス
  - H1のSMA5・SMA20デッドクロス
  - H1のSMA5・SMA60デッドクロス
- デッドクロスが成立した確定バーの次に存在する同時間足の始値で売る。
- 買い時点ですでに売却側のSMA5が比較対象SMAを下回っていても、それだけでは売らない。
- 買った後に新しく成立した最初のデッドクロスで売る。
- 検証終了までデッドクロスがない場合は、最後の確定M5終値で決済する。

### 共通条件

- ゴールデンクロス:

```text
前の確定バー: SMA5 <= 比較対象SMA
現在の確定バー: SMA5 > 比較対象SMA
```

- デッドクロス:

```text
前の確定バー: SMA5 >= 比較対象SMA
現在の確定バー: SMA5 < 比較対象SMA
```

- 入力履歴の末尾1本は未確定足として除外する。
- 各戦略は独立して検証する。
- 1戦略につき同時に保有できるポジションは1つだけとする。
- ポジション保有中の追加購入、ナンピン、ピラミッディング、部分決済は行わない。
- 戦略IDは`long_<買い時間足>_5_60__death_<売り時間足>_5_<20または60>`とする。
- 例: `long_H1_5_60__death_M30_5_60`は、H1のSMA5・SMA60ゴールデンクロスで買い、M30のSMA5・SMA60デッドクロスで売る。
