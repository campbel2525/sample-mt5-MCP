# 概要

MT5にMCPの機能が追加されてAIから簡単に利用できるようになりました

MCPを使うと

- MT5からチャートの情報を取得できる
- 売買をMT5から取得できる
- チャートの情報を取得できるのでAIに分析してもらえる

と言いたメリットがあります。

今回は以下の流れを想定しています。

1. MCP経由でMT5からチャートの情報を取得
2. こちらで用意したPythonを利用してテクニカルチャートの計算を行う
3. AIで操作を行う

- 売買を行う
- Slack, Lineにメッセージを送信する

実行環境は以下の通り

- MT5をMAC上で実行し適切にMT5のMCPの設定を行う
- Docker上でcodexを実行
- codexは定期的に実行しチャートの分析を行い売買を行う

# 詳細

## 1. MCP経由でMT5からチャートの情報を取得

MCPから取得されるデータ情報

```
{
  "symbol": "BTCUSD",
  "period": "H1",
  "data_available_from": "2013.01.01 00:00:00",
  "history": [
    {
      "time": "2026.08.15 19:00:00",
      "open": 63075.25,
      "high": 63101.75,
      "low": 63040.25,
      "close": 63072.45,
      "tick_volume": 193,
      "spread": 4000
    }
  ]
}
```

## 2. こちらで用意したPythonを利用してテクニカルチャートの計算を行う

`scripts/technical_chart.py`は、MCPから取得したJSONを読み込み、次の結果を箇条書きで出力します。

- 短期移動平均線と長期移動平均線のクロス判定
- 短期移動平均線と中期移動平均線のクロス判定
- RSIの値

MCPから取得したJSON文字列を`--market-json`に指定して実行します。JSON文字列はシェルに展開されないようにシングルクォートで囲みます。

```bash
docker compose exec app python scripts/technical_chart.py \
  --ma-periods 5,20,60 \
  --ma-method SMA \
  --applied-price CLOSE \
  --rsi-period 14 \
  --bar-shift 1 \
  --market-json \
  '{"symbol":"BTCUSD","period":"H1","data_available_from":"2013.01.01 00:00:00","history":[{"time":"2026.08.15 19:00:00","open":63075.25,"high":63101.75,"low":63040.25,"close":63072.45,"tick_volume":193,"spread":4000}]}'
```

引数は次のとおりです。

- `--ma-periods`: 短期、中期、長期の移動平均期間。既定値は`5,20,60`
- `--ma-method`: 移動平均方式。`SMA`、`EMA`、`SMMA`、`LWMA`から指定。既定値は`SMA`
- `--applied-price`: MAとRSIの適用価格。`CLOSE`、`OPEN`、`HIGH`、`LOW`、`MEDIAN`、`TYPICAL`、`WEIGHTED`から指定。既定値は`CLOSE`
- `--rsi-period`: RSIの期間。既定値は`14`
- `--bar-shift`: 判定対象を最新バーから何本戻すか。`0`は最新バー、`1`は1本前。既定値は`1`
- `--market-json`: MCPから取得したJSON文字列

出力例

```text
- 短期移動平均線と長期移動平均線: ゴールデンクロス
- 短期移動平均線と中期移動平均線: クロスなし
- RSI: 63.42
```

指定した移動平均期間とRSI期間に対して履歴が不足している場合は、`判定不可（データ不足）`または`算出不可（データ不足）`を出力します。

## 設定

- 対象銘柄: GOLD
- 通知先: slackとlineの両方
- 対象時間足:
  - M15（15分足）
  - M30（30分足）
  - H1（1時間足）
  - H4（4時間足）
  - D1（日足）
  - W1（週足）
- 使用するローソク足:
  - M15、M30、H1、H4、D1: 最新120本
  - W1: 最新50本
- 移動平均方式: SMA
- 適用価格: CLOSE
- RSI期間: 14
- bar-shift: 1

このプロンプトでは、「3日線」「5日線」「7日線」「10日線」「20日線」「60日線」「100日線」は、D1の確定バーから計算した各期間のSMAを指します。
「10週線」は、W1の確定バーから計算した10期間のSMAを指します。
M15、M30、H1、H4のSMAは日数ではなく各時間足のバー数で計算し、日足・週足の判定を補強または否定する材料として使用してください。
「価格」はGOLDの価格を指します。

## 実行手順

1. 新しい実行セッションでは、最初のツール呼び出しとしてMT5 MCPのget_workspace_infoを呼び出してください。

2. get_workspace_infoが成功した後、MT5 MCPのget_chart_historyを使用し、GOLDのM15、M30、H1、H4、D1、W1を取得してください。

3. get_chart_historyには実行時点をdatetime_toとして指定してください。M15、M30、H1、H4、D1は120本以上、W1は50本以上を取得できるdatetime_fromを指定してください。

4. 取得結果をtimeの昇順に並べ、M15、M30、H1、H4、D1は末尾の最新120本、W1は末尾の最新50本だけを使用してください。必要本数に満たない時間足がある場合は買い候補と判断せず、データ不足として記録してください。

5. 各時間足について、次の形式のJSONを作成してください。

{
  "symbol": "GOLD",
  "period": "<時間足>",
  "data_available_from": "<MCPの取得結果>",
  "history": [時間足ごとの必要本数のローソク足]
}

6. M15、M30、H1、H4、D1のJSONを1つずつ、次のコマンドの--market-jsonへ安全に渡して実行してください。

docker compose exec -T app python scripts/technical_chart.py \
  --ma-periods 5,20,60 \
  --ma-method SMA \
  --applied-price CLOSE \
  --rsi-period 14 \
  --bar-shift 1 \
  --market-json '<JSON文字列>'

W1は次のコマンドで実行してください。

docker compose exec -T app python scripts/technical_chart.py \
  --ma-periods 5,10,20 \
  --ma-method SMA \
  --applied-price CLOSE \
  --rsi-period 14 \
  --bar-shift 1 \
  --market-json '<W1のJSON文字列>'

7. コマンドが失敗した時間足は結果を推測せず、買い候補の判定から除外してエラーとして記録してください。

8. 取得した確定バーのcloseから、M15、M30、H1、H4ではSMA5、SMA20、SMA60を計算してください。D1ではSMA3、SMA5、SMA7、SMA10、SMA20、SMA60、SMA100を計算し、W1ではSMA5、SMA10、SMA20を計算してください。

9. 各SMAについて、分析対象バーの値、1本前の値、大小関係、上向き・横ばい・下向きを確認してください。上向き・横ばい・下向きを数値で確認できない場合は推測しないでください。

10. 各時間足について、次の結果を整理してください。

- technical_chart.pyが出力した移動平均線のクロス状況
- SMAの大小関係と方向
- RSI
- 分析対象バーの時刻
- 分析対象バーの始値、高値、安値、終値、陽線または陰線
- 直近4本、7本、10本の値動き
- 直近の確定した高値と安値を更新したか
- レンジ、反発、押し目、戻りが確認できるか

確認できなかった内容を推測で補完しないでください。判定に必要な情報を確認できない項目は「判定不可」としてください。

## 判定基準

### 買い条件

次のいずれかを確定バーで明確に確認できた場合だけ、買い条件を1件満たしたものとして扱ってください。

- 下落から横ばいへ移り、レンジ下限から上がり始めた。
- D1でSMA5＞SMA20＞SMA60の順になり、3本とも上向いている。
- D1の上昇トレンド中にSMA20付近まで押した後、陽線がSMA5を下から上へ抜けた。「下半身」の買いシグナル。
- D1の価格またはSMA5が前の安値を割らずに反発した、または前の高値を突破した。
- 長い下落後にD1のSMA5の高値と安値が切り上がり、さらに下半身が出て底打ちを確認した。
- D1のSMA10またはW1のSMA10が前の高値を越えた。
- D1のSMA3、SMA5、SMA7、SMA10が密集した後、前回より高い位置から上向きに広がり始めた。

ゴールデンクロスは買い条件を補強する分析材料として使用してください。ゴールデンクロスだけでは買い条件を満たしたものとしないでください。

### 買いを見送る反対条件

次の項目はカラ売りを実行する条件ではなく、買い候補を見送るための反対シグナルとして扱ってください。

- 高値を更新できない、節目の価格で反落する、または前の安値を割る弱さがある。
- D1でSMA100＞SMA60＞SMA20＞SMA5の下降順となり、陰線がSMA5を上から下へ割った。「逆下半身」の売りシグナル。
- 上昇トレンドが崩れ、陰線がSMA5を割った。さらに価格またはSMA5がSMA20を割った場合は、より強い反対シグナルとする。
- 下向きのSMA20またはSMA60まで戻したものの、越えられず再下落した。
- D1のSMA10またはW1のSMA10が前の安値を割った。
- D1のSMA3、SMA5、SMA7、SMA10が密集した後、前回より低い位置から下向きに広がった。
- デッドクロスが検出された。

### 利益確定または買い戻しに相当する条件の扱い

次の項目を確認した場合は新しい買い候補を見送るリスクとして扱い、売買は実行しないでください。

- D1のSMA5が横ばいになった、または価格がSMA5を下回った。
- 直近の上昇が8本から10本程度継続し、上昇の勢いが弱くなった。
- 買い根拠が消えた、または反対シグナルが出た。
- 移動平均線が横ばいでもつれ合っている。

固定の損切り率は、この判定には使用しないでください。

## 買い候補の最終判断

slackとlineへの買い候補通知は、次の条件をすべて満たす場合だけ送信してください。

- 「買い条件」のうち1件以上を、取得した確定データから明確に確認できる。
- M15、M30、H1、H4のうち2つ以上が上昇方向を示している。
- H1、H4、D1、W1に明確な下落方向の矛盾がない。
- 「買いを見送る反対条件」に明確に該当する項目が1件もない。
- 「利益確定または買い戻しに相当する条件」に明確に該当する項目が1件もない。
- ゴールデンクロス、SMAの並びと方向、RSI、直近の値動き、反発または高値更新などから、複数時間足にまたがる具体的な根拠を3点以上説明できる。
- 単一時間足または単一指標だけに依存していない。
- すべての対象時間足でデータとコマンド実行結果が揃っている。
- 時間足間に強い矛盾がない。

条件の一部だけを満たした場合、判断に迷う場合、または定義された形を確認できない場合は買い候補と判断しないでください。
取得していないニュース、出来事、経済指標、保有ポジションなどを根拠にしないでください。

## 買い候補通知

「買い候補の最終判断」の全条件を満たした場合だけ、project/scripts/send_message.pyを通知先ごとに1回ずつ実行してください。

通知には次の内容を含めてください。

- 「買い候補」であり、注文を指示するものではないこと
- 対象銘柄GOLD
- 該当した「買い条件」
- 買い条件を満たした具体的な根拠
- 各時間足のクロス状況、SMAの並びと方向、RSI、直近の値動き
- 確認した反対条件とリスク
- 分析対象バーの時刻
- 実行日時

通知コマンド:

docker compose exec -T app python scripts/send_message.py \
  <slack または line> \
  --message '<買い候補メッセージ>'

条件を満たさない場合は、slackとlineのどちらにも通知しないでください。
同じ分析対象バーと同じ判断根拠による買い候補を、すでにこのチャットで通知している場合は再通知しないでください。

## 最終報告

実行後、次の内容を簡潔に報告してください。

- 各時間足の分析結果
- 該当した買い条件、または該当しなかった理由
- 反対条件とリスクの確認結果
- 買い候補と判断したか
- slackとlineそれぞれへの通知有無
- 通知しなかった場合はその理由
- データ取得またはコマンド実行のエラー

ゴールデンクロスまたはデッドクロスだけを通知したと報告しないでください。
